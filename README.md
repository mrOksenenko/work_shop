# OKS Desk

Десктопный интерфейс (Electron) для Claude Code CLI со своей историей чатов.

## Запуск

```bash
npm install
npm start
```

Нужен установленный `claude` CLI с выполненным входом (`claude /login`).
Автор: [Kirill Oksenenko](https://github.com/mrOksenenko)

История чатов хранится в папке данных приложения (`~/Library/Application Support/OKS Desk/chats/`).
